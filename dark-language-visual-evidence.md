# Mode sombre et langues — contrôle visuel

L’accueil s’affiche avec un fond sombre, une bannière lisible et un header contrasté. Le menu latéral ouvert affiche trois boutons de langue sous forme d’icônes seules : France, Algérie/arabe et Royaume-Uni/anglais. Les boutons disposent de libellés accessibles et d’un état actif. Le bouton de thème lune/soleil est présent dans le menu global interne ; les préférences sont stockées dans `localStorage` et appliquées sur `html`, `body`, `lang` et `dir`.

Aucune publication, authentification, recherche ou opération Appwrite n’a été déclenchée pendant le contrôle.

## Contrôle final du menu d’accueil

Le menu déroulant de l’accueil affiche les icônes seules 🇫🇷, 🇩🇿 et 🇬🇧 avec leurs libellés accessibles. Le bouton soleil est également visible avec l’intitulé « Activer le mode clair », ce qui confirme que le mode sombre est actif par défaut et que la bascule est fonctionnelle.
